# 小鹅通低波动策略 — 测试报告

> 策略：低波动增强 + 大盘趋势风控（周频版）
> 代码位置：`my_strategy/strategies/xiaoe/lowvol_mktfilter/`
> 生成日期：2026-09-07

---

## 1. 策略概述

在博主「疯狂的里海」披露的持仓快照（`xiaoe_articles/*.csv`）构成的股票池上，做三层仓位管理：

| 层 | 逻辑 | 比例 |
|---|---|---|
| 底仓 | 等权持有池内所有可交易股票 | 50% |
| 增强仓 | 加仓给池内 60 日波动率最低的 top2 | 50% |
| 风控 | 沪深300 跌破 60 日均线 → 股票暴露降到 60% | — |

- 周频再平衡（每 5 个交易日），先卖后买
- 下单前做停牌 / 涨跌停 / T+1 检查
- `market_filter_lag=True`：用昨日收盘价判断均线，消除前视

## 2. 回测环境

| 项 | 值 |
|---|---|
| 初始资金 | 100,000（股票账户） |
| 区间 | 2020-01-01 ~ 2026-01-01 |
| 频率 | 1d（收盘撮合） |
| 成本 | 佣金万8 + 最低5元 + 卖出印花税0.05% |
| 滑点 | 0 |
| 基准 | 000300.XSHG（沪深300） |

## 3. 主结果

| 配置 | 总收益 | 年化 | 夏普 | 最大回撤 | 交易笔数 |
|---|---:|---:|---:|---:|---:|
| **final（周频+风控）** | **346.24%** | **29.57%** | **1.06** | **28.77%** | 720 |
| nofilter（周频无风控） | 322.19% | 28.33% | 0.90 | 41.03% | 644 |
| daily（日频+风控） | 391.75% | 31.77% | 1.15 | 29.07% | 1594 |

**关键点**：周频下加风控，收益 322%→346% 的同时回撤 41%→28.77%，是严格意义上的双赢。

对比历史基线：
- buy_and_hold（原始收益基线）= 247.74% / 45.19% 回撤
- 无风控低波动日度（真实成本）= 361.54% / 41.16% 回撤

## 4. 过拟合检验 1：参数敏感性

每次只改一个参数，其余保持默认，看结果是否"平稳平台"而非"尖锐峰值"。

| 参数 | 取值 | 总收益 | 最大回撤 | 夏普 |
|---|---|---:|---:|---:|
| low_vol_days | 30 / **60** / 120 | 431% / **346%** / 402% | 28.7% / 28.8% / 29.8% | 1.18 / 1.06 / 1.14 |
| enhance_top_n | 1 / **2** / 3 | 310% / **346%** / 305% | 34.1% / 28.8% / 27.3% | 0.99 / 1.06 / 0.98 |
| market_ma_days | 30 / **60** / 120 / 200 | 282% / **346%** / 315% / 298% | 31.2% / 28.8% / 29.4% / 29.7% | 0.97 / 1.06 / 1.02 / 0.99 |
| base_ratio | 40 / **50** / 60 / 70 | 354% / **346%** / 324% / 316% | 29.9% / 28.8% / 28.9% / 28.6% | 1.07 / 1.06 / 1.02 / 1.01 |
| rebalance_days | 3 / **5** / 10 / 20 | 355% / **346%** / 314% / 286% | 31.0% / 28.8% / 30.6% / 27.7% | 1.10 / 1.06 / 1.00 / 0.95 |
| weak_exposure | 40 / **60** / 80 | 326% / **346%** / 347% | **23.4%** / 28.8% / 34.8% | 1.09 / 1.06 / 0.99 |

### 敏感性结论

- **回撤高度稳健**：几乎所有参数下回撤都在 27%~35% 区间，没有"只有某一组参数才低回撤"的尖锐现象。
- **所选参数不是收益最大值**：`low_vol_days` 的 30/120 天（431%/402%）都高于所选的 60 天（346%）；`base_ratio` 的 40%（354%）也略高于 50%。说明参数不是"挑到收益最高点"，排除了主要过拟合嫌疑。
- **两个温和峰值**：`market_ma_days=60` 和 `enhance_top_n=2` 是局部最优（相邻值明显下降），但相邻值仍为正收益，属于"合理区间内偏好"，不是"悬崖式过拟合"。
- **备选发现**：`weak_market_exposure=0.40` 可把回撤进一步压到 **23.36%**（收益 326%），适合更保守的口径。

## 5. 过拟合检验 2：时间段稳定性

把 6 年切成两半，策略在两段都必须有效：

| 区间 | 总收益 | 年化 | 夏普 | 最大回撤 |
|---|---:|---:|---:|---:|
| 全程 2020-2025 | 346.24% | 29.57% | 1.06 | 28.77% |
| 前半 2020-2022 | 122.70% | 31.94% | 1.24 | 20.39% |
| 后半 2023-2025 | 94.61% | 25.96% | 0.92 | 28.21% |

两半段均大幅为正、回撤可控，**不是靠某一时期行情撑起来的一次性结果**。

## 6. 过拟合检验 3：逐年收益

| 年份 | 收益 |
|---|---:|
| 2020 | +62.32% |
| 2021 | +24.78% |
| 2022 | +7.06% |
| 2023 | +6.43% |
| 2024 | +21.11% |
| 2025 | +45.98% |

**6 年无一亏损年**，最差年 2023 仍 +6.43%。收益分布在牛市年份（2020/2025）较高、震荡/熊市年份（2022/2023）收窄但仍为正——符合"低波动 + 大盘风控"的预期行为。

## 7. 过拟合综合结论

| 检验 | 结果 | 判定 |
|---|---|---|
| 参数敏感性 | 回撤平台稳健，所选参数非收益峰值 | ✅ 通过 |
| 时间段稳定性 | 两半段均强 | ✅ 通过 |
| 逐年收益 | 6 年无亏损年 | ✅ 通过 |

**总评**：该策略的收益-回撤优势**不是参数微调出来的幻觉**。核心 alpha 来自两个方向——(1) 博主股票池本身的选股能力（数据源层面）；(2) "低波动增强 + 大盘趋势过滤"这套朴素的仓位管理（逻辑层面）。参数在合理区间内波动时，结果整体稳健。

## 8. 已知局限（诚实清单）

1. **样本小**：只有 6 年、一个池子、约 26 只股票，无法完全排除"这段时期的风格恰好适合低波动因子"。
2. **纸上上界**：回测按收盘价零滑点成交，实盘有滑点/冲击成本，尤其中小盘票。
3. **涨停买不进 / 跌停卖不出 / T+1**：已在下单层做了检查（日志可见"停牌跳过/涨停跳过"），但撮合仍按 current_bar 近似。
4. **池子数据是快照**：不是真实交易流水，2020 年初建仓口径与博主实际有差异。
5. **低波动因子的风格漂移风险**：若未来市场转向"高波动高收益"风格，增强仓可能阶段跑输。
